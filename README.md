# Спортцентр «Берег» · вечернее расписание

## Кому нужна страница

Администратор стойки открывает расписание на компьютере у входа и показывает его посетителям. На странице три занятия одного вечера. Посетителю важно быстро увидеть название, время и зал. Изображение страницы также можно использовать в сообщении о работе центра.

Расписание уже подготовлено и согласовано. Координатор передал перенос тренировки для страницы и памятки стойки. Для него есть отдельная записка в source. Редактор последовательно обновляет страницу и памятку, проверяет соседние занятия и сохраняет состояние каждого этапа в Git.

## Файлы проекта

| Путь | Что находится внутри |
|---|---|
| `index.html` | Страница, которую открывает администратор и видит посетитель |
| `source/schedule-change.md` | Подтверждённая записка об изменении одного занятия |
| `program/reception-note.md` | Памятка администратора для ответа посетителям |
| `.git/` | Локальная история версий со стартовым состоянием |

## Как открыть страницу

В Finder на Mac или Проводнике Windows найди `index.html` в корне этой папки и открой двойным щелчком. Если система предлагает выбор приложения, выбери браузер. Страница работает при открытии с диска, все стили включены в файл.

После сохранения правки обнови ту же вкладку браузера. Сверь, что в адресе указан файл из рабочего проекта. При открытии двух копий папки обращай внимание на полный путь, потому что у обоих файлов будет одинаковое имя index.html.

## Исходное расписание

В стартовой странице йога начинается в 16:00, открытая тренировка — в 17:00, растяжка — в 19:00. Подтверждение нового времени лежит в `source/schedule-change.md`. Порядок занятий, подпись зала и пояснение для посетителей уже согласованы.

## Как проверить изменение

Сначала открой текущую страницу и найди нужное занятие. Прочитай записку координатора. В промпте укажи один рабочий файл, строку, старое значение и ожидаемое новое значение. После правки открой страницу повторно и сверь все три занятия.

Затем посмотри git status и построчное сравнение index.html. Ожидается одна замена времени в одной строке файла. Исходную записку и остальные части страницы сохраняй. После проверки подготовь index.html, просмотри подготовленное сравнение, создай коммит с понятным сообщением и запиши его короткий идентификатор.

В заготовке уже есть стартовый коммит. Имя автора настроено локально для этой папки. История хранится вместе с проектом и доступна при повторном открытии. Для нового дубля возьми свежую копию исходного комплекта вместе со скрытой папкой .git.

## Второй этап той же задачи

После коммита страницы создай AGENTS.md с правилами работы. В новой сессии попроси прочитать его и обновить строку в program/reception-note.md. Сначала покажи план одной замены, затем согласуй и выполни её. Сверь страницу, памятку и подтверждение координатора. На обоих рабочих представлениях ожидаются 18:00 у открытой тренировки, 16:00 у йоги и 19:00 у растяжки. Остальной текст памятки должен сохраниться.

Перед вторым коммитом посмотри status, diff памятки и подготовленное сравнение. В историю этого этапа входят новый AGENTS.md и одна правка program/reception-note.md. Сообщение версии — «Обновить памятку администратора». В журнале сохрани оба идентификатора и результат сопоставления рабочих файлов.
